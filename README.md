# Zyro AI — Original iOS App

This is an original SwiftUI UI for Zyro AI with:
- Home
- Chat
- Voice button
- Create
- Image/video generation placeholders
- Bluetooth/device section
- Custom Zyro visual identity

To make it a working production app, connect the chat/create actions to a secure backend and add the appropriate iOS permissions and APIs.

Do not ship an AI API key directly inside the app. Use a backend to protect credentials.

For Bluetooth, use Apple's Core Bluetooth APIs for supported Bluetooth Low Energy devices and request the required permissions.
